Playable game

Laurels

A roguelike chess variant on a 6×6 board. Every capture drops a laurel, and if the capturing piece survives the reply, that laurel banks into a reward.

What am I playing?

Chess, with a reason to take the fight

I wanted to know what would happen to chess if you gave it the structure of a roguelike. Ordinary chess punishes greed. This rewards it, but only if you can hold what you have taken.

Games run a few minutes on a 6×6 board. Every run is generated from a seed, so a game can be handed to someone else exactly as you played it.

Open full screen
  1. 1

    Capture, and a laurel drops

    The capturing piece picks it up. What the laurel is worth depends on what you took between common, rare, and jackpot laurels.

  2. 2

    Survive a turn, and it banks

    Hold that piece through the opponent's reply and the laurel resolves into a reward — extra turns, zombie pieces, upgrades. Lose the piece and they take the laurel with it. Jackpots let you pick one of three.

  3. 3

    No check, no checkmate

    There are no pins and nothing is illegal on account of your king. Capture theirs and the game ends there.

Runs with a mouse or by touch. On a small screen it is worth opening it in its own tab.

How it is built

A pure engine with the game painted on top

TypeScript, React and Vite, with the board drawn as plain HTML5 canvas on a requestAnimationFrame loop where none of the game rules need to know that a screen exists.

Deterministic from a seed

The engine is pure and has no DOM access. Randomness comes from a mulberry32 generator seeded per run, so the same seed always replays the same game. There are cross-run determinism tests to keep it that way.

Rewards are data

Each reward is a row in a registry — some metadata and a pure apply function. Adding a new mechanic means adding a row rather than threading logic through the game loop.

A bot that wants the laurels

Alpha-beta minimax that knows regicide ends the game and values laurels rather than counting material. A bot that only weighs pieces plays this variant badly.
